Now You See Me

A precise, lightweight resource monitor for Linux. Top bar, desktop app, terminal UI and CLI.

Install on Ubuntu or Debian

Add the signed repository once; updates then arrive with apt upgrade.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://sheheemmulakkal.github.io/now-you-see-me/apt/nysm-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/nysm-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/nysm-archive-keyring.gpg] https://sheheemmulakkal.github.io/now-you-see-me/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/nysm.list
sudo apt update
sudo apt install nysm nysm-tray nysm-desktop

nysm (CLI, terminal UI, collector) and nysm-tray need Ubuntu 22.04 or newer; nysm-desktop needs Ubuntu 24.04 or newer. amd64 and arm64.

Verify the signing key

The repository is signed by Now You See Me APT repository, fingerprint

3DF6 A0A9 326B ECFE A1C5  7B50 4127 009F CA3F C576

Check with gpg --show-keys /etc/apt/keyrings/nysm-archive-keyring.gpg. Armored copy: nysm-archive-keyring.asc.

Remove

sudo apt remove nysm-desktop nysm-tray nysm
sudo rm /etc/apt/sources.list.d/nysm.list /etc/apt/keyrings/nysm-archive-keyring.gpg
